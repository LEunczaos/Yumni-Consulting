# YUMNI Consulting — landing page (React + Vite)

Généré depuis la frame **Moquet** du fichier Figma `New-moquet.fig`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

- `src/styles/tokens.css` : couleurs, polices, espacements (extraits du Figma)
- `src/data/content.js` : tous les textes + liens (WhatsApp / rendez-vous à renseigner)
- `src/components/` : un composant par section

Polices : Space Grotesk + Source Serif 4 (via @fontsource, auto-hébergées).
